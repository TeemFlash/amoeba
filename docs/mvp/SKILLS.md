# Навыки и роли для реализации MVP

- Astra (gpt-6-astra): правила продукта, контракты состояния, задания и проверка реализации.
- Luna (gpt-6-luna): реализация по контрактам Astra, тесты и исправления замечаний.
- Родитель: координация, проверка работающих сценариев и упаковка результатов.

Применены существующие навыки: `spec-kit` (структура требований), `find-skills` (поиск), `ui-ux-pro-max` (проверка доступности), `subagent-driven-development` (задания и ревью), `test-driven-development` (значимые тесты состояния), `webapp-testing` (проверка в браузере). Общие рекомендации навыков не подменяют требования пользователя и платформенные единицы.

Поиск 2026-11-09: сначала https://skills.sh/, затем `npx skills find 'react native expo'`. Найден официальный Vercel `vercel-labs/agent-skills@vercel-react-native-skills`: CLI показал 271.2K установок, GitHub API — 33742 звезды репозитория. Числа меняются и не гарантируют качество. Для этой задачи достаточно уже имеющихся навыков и официальной документации; новых глобальных навыков не установлено.

Ссылка для дальнейшего изучения: https://skills.sh/vercel-labs/agent-skills/vercel-react-native-skills
Опциональная установка: `npx skills add vercel-labs/agent-skills@vercel-react-native-skills`.

Поиск ui-ux-pro-max для общей дизайн-системы вернул маркетинговый шаблон, не подходящий мобильному MVP; он не применён. Поиск системного масштабирования не дал точного результата; используются правила Astra, проверенные официальные документы и прямой checklist навыка.
