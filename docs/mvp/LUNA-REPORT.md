# Отчёт Luna: локальный Expo MVP

Дата: 2026-11-09. В рамках Astra-плана собран запускаемый TypeScript/Expo проект в `apps/mobile`: React Native Android/iOS исходники и web preview, RU/KZ локализация, типизированная предметная модель и сериализованный AsyncStorage repository.

В демо работают два пути: бытовая помощь с черновиком, районом, интервалом, проверкой, историей и отменой; встречи с просмотром условий, одной доступной, одной заполненной и одной отменённой демонстрационной записью, историей и отменой. Повторный submit с прежним ID идемпотентен, а активная встреча не дублируется. Черновик и история хранятся локально, доступны retry после ошибки записи и подтверждённый сброс. Статусы явно синтетические. Сетевой отправки, аккаунтов, платежей, API и пользовательских свободных полей нет.

### Запуск и проверки

```sh
cd apps/mobile
npm install
npm run start
npm run web
npm test
npm run typecheck
npm run lint
npm run export:web
```

Web preview запускается локально командой Expo; во время разработки он был доступен на `http://localhost:8083`. Порт может измениться, если занят.

### Дизайн и доступность

Интерфейс использует нативные базовые компоненты, спокойную зелёно-кремовую палитру Astra, крупные элементы управления, локализованные статусы и подсказки. Одна вертикальная область прокручивает шапку, demo-предупреждение и содержимое; нижние вкладки остаются отдельными. Для web radio-компонентов задан `aria-checked`, а для native сохранён checked state. После подтверждённых сохранения/отмены используется системное объявление доступности. Это реализовано в исходниках, но само по себе не доказывает работу VoiceOver/TalkBack. Шаблонная иконка Expo временная.

Подтверждённые команды тестирования и npm audit зафиксированы в [`VERIFICATION.md`](VERIFICATION.md). Текущий технический предел: реальные Android/iOS сборки и дикторы не проверялись, а казахские строки требуют редакторской проверки носителем языка. Все названия, места и даты учебные; приложение не обещает настоящую услугу, занятие или ответ.

Итоговое ревью исходников Astra принято. Независимые 20 сценариев браузера прошли без ошибок страницы; восстановление выбранного radio подтверждено `aria-checked`. Дополнительный layout прогон прошёл на 320/390 px и 1×/2× web textScale без горизонтальной прокрутки, а клавиатурный фокус видим. Это границы web preview; JSON и скриншоты QA подготовлены родителем отдельно.
